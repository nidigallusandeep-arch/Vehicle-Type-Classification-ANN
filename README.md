# 🚗 Vehicle Image Classification Using ANN

## 📌 Project Overview

This project focuses on classifying vehicle images using an Artificial Neural Network (ANN). The model takes an input vehicle image and predicts its vehicle category.

The project demonstrates image preprocessing, deep learning model development, model evaluation, and deployment using Streamlit.

## 🚀 Live Demo

🔗 **Try the Application:**  
[Vehicle Image Classification – Live Demo](https://vehicle-type-classification-anngit0d32016052229cmain-mainvenvn.streamlit.app/)

## 🎯 Project Objectives

- Build an ANN model for vehicle image classification.
- Perform image preprocessing and normalization.
- Train and evaluate the ANN model.
- Predict vehicle categories from uploaded images.
- Deploy the trained model using Streamlit.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/nidigallusandeep-arch/Vehicle-Type-Classification-ANN.git
```

Navigate to the project directory:

```bash
cd Vehicle-Type-Classification-ANN
```

Install the required libraries:

```bash
pip install -r Desktop/ANN_model/requirements.txt
```

Run the Streamlit application:

```bash
streamlit run Desktop/ANN_model/app.py
```
